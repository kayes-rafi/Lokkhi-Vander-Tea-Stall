# লক্ষ্মী ভান্ডার টি স্টল (Lokkhi Vander Tea Stall)

Official website for **লক্ষ্মী ভান্ডার টি স্টল** featuring a smooth, GPU-accelerated scroll-driven tea pouring animation, complete menu, stories, gallery, and interactive directions.

## ✨ Features
- **GPU-Accelerated Scroll Hero**: 240-frame sequence rendered via HTML5 `<canvas>` with touch inertia smoothing on smartphones.
- **Mobile First**: Optimized with `100dvh` viewport stability and zero layout-thrashing scroll calculations.
- **Complete Menu**: Real prices and tea varieties (লাল চা, মসলা চা, মালাই চা, দুধ কফি, etc.).
- **Real Location**: Underground, Bridge, Naogaon, Bangladesh with interactive Google Maps.
- **One-Tap Contact**: Direct phone dialer and WhatsApp quick connect.

## 🚀 Deployment on Vercel
This project is structured for zero-configuration deployment on Vercel:
1. Import this repository into Vercel.
2. Select **Other** as the Framework Preset (Static HTML).
3. Click **Deploy**.
